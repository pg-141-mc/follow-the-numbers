# Follow the Numbers

A simple Pygame Zero game where you connect numbered dots in the correct order.

![Follow the Numbers dot](dot.png)

## How to Play

1. Run the game.
2. Click the dots from **1** through **10**.
3. A red line appears between each correct pair of dots.
4. Clicking the wrong dot resets the progress and removes the lines.
5. After all 10 dots are connected, click anywhere to start a new round.

## Requirements

- Python 3
- Pygame Zero

## Running the Game

Install Pygame Zero:

```bash
pip install pgzero
```

Run the game from the repository directory:

```bash
python follow_the_numbers.py
```

## Project Files

- `follow_the_numbers.py` — game logic and rendering
- `dot.png` — dot image used by Pygame Zero
